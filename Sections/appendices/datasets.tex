\chapter{Data, Trigger, and Background Monte Carlo Samples}
\label{app:datasets}

This appendix provides the detailed sample and trigger lists supporting Chapter~\ref{ch:reconstruction}. Tables~\ref{tab:app_datasets_run2} and~\ref{tab:app_datasets_run3} list the Run~2 and Run~3 collision datasets used for the signal selection, fake-rate measurements, and lepton efficiency studies. Table~\ref{tab:app_triggers} gives the analysis, fake-rate, and efficiency-measurement trigger paths used in the corresponding data-taking periods. Tables~\ref{tab:app_mc_run2} and~\ref{tab:app_mc_run3} list the background Monte Carlo simulated samples used for prompt backgrounds, conversion backgrounds, control region studies, and lepton efficiency measurements.

The collision datasets are shown at the MiniAOD level used as input to the NanoAOD-based analysis processing. Curly braces denote multiple run periods or reprocessing versions that share the same dataset version. For the simulated samples, the quoted cross sections include the K-factors used to normalize the generator-level predictions to the perturbative order specified in the tables.
